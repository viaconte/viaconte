# 🧮 Bate o Balancete

Um mini-jogo de somas no navegador. Toque nos números até a soma fechar **exatamente** o valor-alvo.

- Cada acerto vale 10 pontos por número usado (+20 de bônus com 4 ou mais) e dá +2 segundos.
- Passou do alvo? A seleção zera.
- O recorde fica salvo no seu navegador.

**Como jogar:** abra `index.html` em qualquer navegador. Não precisa instalar nada.
